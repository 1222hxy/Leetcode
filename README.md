## 目录说明

- 根目录的 `<题号>.py`：对应题目的练习代码及思路笔记。
- `review/`：复习时重新编写的代码，同一道题可以保留多种写法。
- `.vscode/`：项目的 Python 环境及 Ruff 格式化配置。

第 2 题目前使用 Python 列表进行数位相加练习；力扣原题要求使用链表接口。

## 维护方式

新增题目时，以力扣题号命名文件，并在上表对应位置补充题号、中文标题、原题链接和代码链接。添加复习代码后，更新对应的复习代码列。
